## Family Controls request — draft, not sent

Request page: https://developer.apple.com/contact/request/family-controls-distribution

App / bundle ID: Larpy / `com.vano.larpy`.

Related extension requests:

- Device Activity Monitor: `com.vano.larpy.focus-monitor`
- Shield Configuration: `com.vano.larpy.focus-shield`
- Shield Action: `com.vano.larpy.focus-action`

Purpose:

Larpy is a personal focus and activity companion. An adult user can voluntarily authorize individual Screen Time access, choose distracting apps, categories or websites using Apple's FamilyActivityPicker, and start a 15-, 25- or 50-minute focus session. Selection remains represented by Apple's private tokens. Larpy does not inspect messages, screen contents or browsing history.

FamilyControls obtains individual authorization and the user's selection. ManagedSettings applies a named shield only during the focus block. DeviceActivity schedules the end of focus and the end of an optional timed break. The shield uses original Larpy artwork and offers a return to focus or a request to open Larpy for a break. A break requires a locally stored reason and an explicit 5-, 10- or 15-minute duration. All selected distractions become accessible during the break; the app explains that scope. The app schedules the break's end before removing shields, restores protection on the matching callback or foreground refresh, and provides an explicit End focus action. Revoked authorization ends protection and clears invalid selection tokens.

The app requests access only when the user chooses to set up app blocking. Timer-only use is available without Screen Time authorization. Blocking is not surveillance or parental monitoring of another person's device. Screen Time tokens and focus-session data are stored in the local App Group for the app and its extensions; they are not sent to a backend or advertising service. Focus time and breaks never count as verified Work evidence or independently earn progression rewards.

Validation disclosure for the request/review:

The app and extensions compile and the local focus-session rules have automated checks. Physical-device blocking, shield actions and background re-blocking still require testing with correctly signed entitlements. Do not state that those device tests have passed or attach a simulator recording as proof of real blocking.
