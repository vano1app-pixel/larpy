# Larpy

Session 1 scaffold for the Larpy iOS app.

- SwiftUI iOS app
- Bundle id: `com.larpy.app`
- My Day screen with one character
- Body, Learn, and Work quests
- Local proof logging with photo, link, or number proof

Proof logs are stored locally in the app's Application Support folder as JSON. Photo proof files are copied into a local `ProofPhotos` folder.
